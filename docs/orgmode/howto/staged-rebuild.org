#+title: Rebuild an EasyBuild install without exposing a partial tree

* Probe the build host

Run probes as the CI account and against the live software filesystem.

#+begin_src sh
eb-staged-rebuild probe --path "$EASYBUILD_INSTALLPATH_SOFTWARE"
#+end_src

Use an explicit =--backend bwrap= or =--backend userns= when site policy
forbids the unsandboxed install-path fallback.

* Preview the transaction

#+begin_src sh
eb-staged-rebuild run \
  --software "$EASYBUILD_INSTALLPATH_SOFTWARE" \
  --modules "$EASYBUILD_INSTALLPATH_MODULES" \
  --module Name/version \
  --dry-run \
  -- Name-version-toolchain.eb --robot
#+end_src

Dry-run does not invoke EasyBuild or create a journal. Check the selected
backend, the exchange result for this filesystem, and the staged command.

* Run the rebuild

Keep the state root on the software filesystem.

#+begin_src sh
eb-staged-rebuild run \
  --software "$EASYBUILD_INSTALLPATH_SOFTWARE" \
  --modules "$EASYBUILD_INSTALLPATH_MODULES" \
  --state-root "$(dirname "$EASYBUILD_INSTALLPATH_SOFTWARE")/.eb-staged-rebuild" \
  -- Name-version-toolchain.eb --robot
#+end_src

The stable =Name/version= path becomes the complete staged tree. The previous
tree remains at =Name/.version.<run-id>=.

* Set permissions before the swap

Name a program with =--prepare= (an absolute path) to set ownership, modes
or ACLs on the staged tree and on each module's prepared file after the
build and before the live directory is exchanged.

#+begin_src sh
eb-staged-rebuild run \
  --software "$EASYBUILD_INSTALLPATH_SOFTWARE" \
  --modules "$EASYBUILD_INSTALLPATH_MODULES" \
  --prepare /usr/local/sbin/finalize-install \
  -- Name-version-toolchain.eb --robot
#+end_src

The program gets one argument, a JSON file with =run_id=, =stage_software=,
=live_software= and one entry per module (=rel=, =staged=, =prepared=,
=live_module=). A non-zero exit is the command's exit and nothing is
swapped; a tree the program leaves without =easybuild/*.eb= blocks the
whole publication. A mode or ACL set on =prepared= reaches the live module
file even when its text did not change. An install sealed read-only by
EasyBuild publishes as it is.

* Record the build in a ledger

Two commands run beside =run=, each as a Python module, against the
=eb-stack= ledger CLI (0.5.2 or later).

#+begin_src sh
python3 -m eb_staged_rebuild.build_events \
  --config /etc/build-events/ledger.json \
  --metadata "$WORKSPACE/build-event.json" \
  -- eb Name-version-toolchain.eb --robot
#+end_src

=build_events= appends a =started= record before the command runs and a
=finished= or =aborted= record after it, through an outbox that survives a
crash; exit 75 means an event is still pending, and the same command
delivers it. Every field of the config and the metadata is in
[[file:../../build-events.md][docs/build-events.md]].

#+begin_src sh
python3 -m eb_staged_rebuild.ledger_maintenance anchor \
  --eb-stack /abs/eb-stack --log /abs/ledger/stack.jsonl \
  --key /abs/keys/ledger.pem --public-key /abs/keys/ledger.pub \
  --anchors /abs/anchors
#+end_src

=ledger_maintenance= publishes one signed anchor per day, proves the anchor
chain (=verify-anchors=), backfills observed history from a pinned manifest
(=backfill=) and writes package history from a verified log (=project=).
The commands, their refusals and their exit codes are in
[[file:../../ledger-maintenance.md][docs/ledger-maintenance.md]].

* Recover or roll back

#+begin_src sh
eb-staged-rebuild status --state-root /path/to/.eb-staged-rebuild
eb-staged-rebuild resume --state-root /path/to/.eb-staged-rebuild RUN_ID
eb-staged-rebuild rollback --state-root /path/to/.eb-staged-rebuild RUN_ID
#+end_src

=resume= repairs an interrupted ordinary-rename fallback before continuing.
=rollback= exchanges the previous tree back into the stable path.

* Collect retired trees

Choose the grace period from the site's longest job.

#+begin_src sh
eb-staged-rebuild gc \
  --state-root /path/to/.eb-staged-rebuild \
  --grace-hours 144 \
  --dry-run
#+end_src

Review the exact hidden paths before running without =--dry-run=.
